## Sources and promotion criteria

An authorized independent binding to an existing Dot, a fresh conversation, native action and retrieval after reconnect remain unavailable. The experimental plugin fixture exercises a signed callback echo, scoped sample read and sum return, retry, expiry and revocation in memory and SQLite. No installed plugin or authenticated native Dot participated. The adapter advertises zero operations. - **Grok Bot.** At `a4ec360`, the configured `task` fixture posts to the issued webhook origin and path without a quota checkpoint. The direct transport takes a `WebhookGrant`. Registered v1 callers use the existing interface. HTTP 200 produces one `ACCEPTED` receipt with `routine_accepted: true`, `native_reply: false` and `native_session_observed: false`. The connector discards response bodies, stops at redirects and records any observed non-200, including 5xx, as a rejection. A timeout after one POST leaves submission uncertain. QA ran 35 Grok tests on Python 3.11 and the full Python 3.14 suite (103 passed, one skipped). No native routine was sent. Native identity, completion and result retrieval remain open. [Grok Bot investigation](https://github.com/Section9Labs/tachi/blob/a4ec3607bff35b702fd9c0cbfd4e82cfbd0287ed/docs/providers/grok.md)
